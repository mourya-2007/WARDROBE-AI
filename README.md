# Wardrobe AI

The latest Wardrobe AI project source is included in [`Wardrobe-AI-Source.zip`](./Wardrobe-AI-Source.zip).

## Run locally

1. Download and extract `Wardrobe-AI-Source.zip`.
2. Open the extracted `wardrobe-ai-optimized` folder in your terminal.
3. Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

## Included features

- Apple-inspired landing page with animated text marquee and rotating fashion imagery.
- Dark, Mac Pro-inspired application workspace.
- My Wardrobe with garment preview and close interactions.
- Landscape occasion carousel.
- AI Stylist with larger cards, outfit-generation animation, and ready-state modal.
- Responsive layouts and motion-aware styling.

The outfit suggestions are currently sample recommendations from the project; a live AI styling API is not connected.
